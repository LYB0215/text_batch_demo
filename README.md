# CSV 文本清洗与校验工具

## 项目作用

读取 CSV 格式的文本数据，自动完成文本清洗（去首尾空白、删除换行符）、长度校验，将清洗结果、文本长度、有效判定写入结果 CSV 文件；内置文件不存在、编码错误、写入失败等异常防护，保证程序异常时正常退出不崩溃。

## 运行环境

- Python 3.x
- 仅使用 Python 标准库 `csv`，无需安装第三方依赖

## 运行方式

1. 准备输入文件 `raw_text.csv`，第一列为待处理文本，表头为 `text`
2. 在项目目录执行命令：

-python main.py

3. 运行成功后生成结果文件 `result_text.csv`

## 输入输出示例

### 输入示例（raw_text.csv）
```
text
   这是第一段足够长的测试文本，用来验证清洗和长度校验逻辑是否正常工作
短文本
另一段用于测试的长文本，覆盖空行、首尾空格等边界场景，保证流程正常
```

### 输出示例（result_text.csv）

```
text,length,valid
这是第一段足够长的测试文本，用来验证清洗和长度校验逻辑是否正常工作,52,True
短文本,3,False
另一段用于测试的长文本，覆盖空行、首尾空格等边界场景，保证流程正常,49,False
```

## 异常处理

- 输入文件不存在：提示「输入文件不存在」并正常退出
- 文件编码错误：提示「读取编码错误」并正常退出
- 写入权限 / 磁盘问题导致写入失败：提示「写入失败」
- 其他未预料异常：打印具体错误信息并正常退出
